Puesta a punto

Preparar el entorno y compilar tu primer programa

Objetivo

Instalar un compilador de C, escribir un programa mínimo, compilarlo y ejecutarlo. Al terminar debes ver un mensaje impreso en la terminal.

C es un lenguaje compilado: escribes texto en un archivo .c, un programa llamado compilador lo traduce a instrucciones de máquina (un ejecutable), y entonces ejecutas ese archivo. No hay intérprete como en Python; siempre hay dos pasos: compilar y ejecutar.

Instalar el compilador

  • Linux: normalmente ya está gcc. Si no: sudo apt install build-essential.
  • macOS: instala las Command Line Tools con xcode-select --install (te da clang, compatible).
  • Windows: usa WSL (recomendado) o instala MSYS2/MinGW para tener gcc.

Concepto de C · estructura mínima de un programa

Todo programa en C empieza a ejecutarse por la función main. La biblioteca estándar te da funciones ya hechas; para usar printf incluimos la cabecera <stdio.h> con la directiva #include. El valor que main devuelve (return 0;) le indica al sistema operativo si todo fue bien (0) o hubo error (distinto de 0).

Compila y ejecuta desde la terminal, en la carpeta donde guardaste el archivo:

terminal
$ gcc -Wall -O2 hola.c -o hola   # compila hola.c y crea el ejecutable "hola"
$ ./hola                        # ejecuta
Trazador de rayos: preparado.

Qué significan las banderas

-Wall activa todos los avisos (úsalo siempre; los avisos suelen ser errores disfrazados). -O2 optimiza el código (lo hará más rápido, importante para un trazador de rayos). -o hola nombra el ejecutable. Más adelante añadiremos -lm para enlazar la biblioteca matemática.

Pista · el error más común

Si al ejecutar escribes hola y dice «orden no encontrada», recuerda el ./ del principio: en Linux/macOS hay que decir explícitamente «ejecuta el archivo que está aquí», con ./hola.

Entrega

  • Captura de la terminal mostrando la compilación y la salida del programa.
  • Modifica el mensaje e imprime también tu nombre en una segunda línea usando un segundo printf.
