Estructuras y cabeceras

El tipo vec3: nuestra herramienta básica

Objetivo

Crear un tipo vec3 (vector de 3 componentes) con funciones para operar con él, repartido en su propio archivo de cabecera. Reescribir la Tarea 1 usando vec3 para representar el color de cada píxel.

Un trazador de rayos vive de vectores de tres componentes: los usamos para puntos en el espacio, para direcciones y para colores RGB. En C++ el libro define una clase vec3 con operadores +, *, etc. En C no hay sobrecarga de operadores, así que definimos un struct y una función por cada operación.

Concepto de C · struct, typedef y paso por valor

Un struct agrupa varias variables bajo un mismo nombre. Con typedef le damos un nombre corto para no escribir struct vec3 cada vez. Nuestras funciones reciben y devuelven vec3 por valor (una copia): para vectores de 3 doubles es barato y hace el código muy parecido a la fórmula matemática.

Concepto de C · archivos de cabecera y guardas de inclusión

Ponemos el tipo y sus funciones en vec3.h. El bloque #ifndef VEC3_H … #define VEC3_H … #endif es una guarda de inclusión: evita que el archivo se procese dos veces si se incluye desde varios sitios. Usamos static inline para poder definir las funciones en la cabecera sin provocar errores de «símbolo duplicado» al enlazar.

Recordatorio de álgebra vectorial

El producto escalar a·b = aₓbₓ + a_yb_y + a_zb_z mide cuánto se alinean dos vectores; será clave para iluminación y reflexión. La norma |a| = √(a·a), y un vector unitario es a/|a|. Fíjate en que vec3_length_squared evita la raíz cuadrada cuando solo necesitamos comparar longitudes: es una micro-optimización habitual.

Compilar con la biblioteca matemática

Como vec3.h usa sqrt, ahora hay que enlazar libm con -lm (que debe ir al final): gcc -Wall -O2 main.c -o rt -lm. Solo compilamos main.c; los .h se incluyen con #include, no se compilan aparte.

Pista · devolver structs no es «lento»

Puede sorprender devolver copias de vec3 por todas partes. Con -O2 el compilador elimina casi todas esas copias. Prioriza la claridad; el código se leerá igual que las fórmulas de tus apuntes de física.
