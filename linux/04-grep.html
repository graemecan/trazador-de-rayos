Búsqueda de texto

grep: buscar con patrones

Objetivo

Buscar líneas que contienen un texto o un patrón (expresión regular) en ficheros o en la salida de otro programa, con grep y sus opciones más útiles.

grep patrón fichero imprime las líneas del fichero que contienen el patrón. Sin fichero, lee stdin, así que encaja al final de una tubería.

terminal
$ grep ERROR render.log
2026-11-18 11:15:03 ERROR no se pudo abrir textura.ppm
$ grep -n WARN render.log           # -n: con número de línea
2:2026-11-18 10:02:11 WARN  pocas muestras: la imagen tendra ruido
8:2026-11-19 09:00:01 WARN  memoria: 512 MB reservados
$ grep -c INFO render.log           # -c: solo cuántas
6
$ grep -v INFO render.log           # -v: las que NO contienen INFO
2026-11-18 10:02:11 WARN  pocas muestras: la imagen tendra ruido
2026-11-18 11:15:03 ERROR no se pudo abrir textura.ppm
2026-11-19 09:00:01 WARN  memoria: 512 MB reservados

Pista · grep busca texto, no palabras

Queremos las líneas que marcan el fin de un render:

$ grep fin render.log
2026-11-18 10:02:11 INFO  inicio escena=final ancho=400 muestras=10
2026-11-18 10:04:37 INFO  fin tiempo=146.2
...

¡También salen las de escena=final! La opción -w exige que el patrón sea una palabra completa: grep -w fin render.log devuelve solo las tres líneas correctas.

OpciónEfecto
-iignora mayúsculas/minúsculas
-nmuestra el número de línea
-ccuenta las líneas que coinciden
-vinvierte: líneas que no coinciden
-wsolo palabras completas
-oimprime solo el trozo que coincide, no la línea entera
-rbusca recursivamente en un directorio
-lsolo los nombres de los ficheros con coincidencias
-Eexpresiones regulares extendidas (+ ? | () sin barras)

Expresiones regulares

El patrón es una expresión regular: un pequeño lenguaje para describir texto. Ponlo siempre entre comillas simples para que la shell no interprete los caracteres especiales.

PatrónCoincide con
.cualquier carácter
^ $principio / final de línea
[0-9]un carácter del conjunto (aquí, una cifra); [^0-9]: cualquiera que no lo sea
x*cero o más x
x+una o más x (con -E)
x?x opcional (con -E)
a|ba o b (con -E)
\.un punto literal (el \ «escapa» el carácter especial)
terminal
$ grep -E 'WARN|ERROR' render.log            # avisos o errores
$ grep '^2026-11-19' render.log                 # líneas que EMPIEZAN por esa fecha
$ grep -oE 'escena=[a-z]+' render.log | sort | uniq -c
      2 escena=final
      1 escena=vidrio
$ grep -oE 'muestras=[0-9]+' render.log      # solo el trozo que coincide
muestras=10
muestras=50
muestras=100

Buscar en tu código

grep -r es la forma más rápida de encontrar dónde se usa una función en un proyecto:

terminal
$ grep -rn 'vec3_unit' src/          # ¿dónde se llama a vec3_unit?
$ grep -rl 'malloc' src/             # ¿qué ficheros reservan memoria?
$ grep -rn 'TODO' --include='*.c' .  # tareas pendientes, solo en ficheros .c
$ gcc -Wall main.c -o rt -lm 2>&1 | grep -c warning   # ¿cuántos avisos?

Ejercicios

  • Muestra, con número de línea, todas las líneas de render.log del día 18 que no sean INFO.
  • Con grep -o y una tubería, obtén el mayor valor de ancho= que aparece en el log.
  • Lista las medidas de medidas.csv cuyo tiempo empieza por 2.. Cuidado: el punto es especial.
  • En tu proyecto del trazador, encuentra todas las líneas que declaran una función que devuelve vec3 (empiezan por vec3 o static inline vec3 ).
