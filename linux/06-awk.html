Datos en columnas

awk: procesar datos por columnas

Objetivo

Usar awk para trabajar con datos organizados en columnas: seleccionar campos, filtrar filas por condiciones numéricas y calcular sumas, medias y desviaciones, todo en una línea.

Concepto · patrón { acción }

awk es un pequeño lenguaje de programación (su sintaxis recuerda mucho a C). Lee la entrada línea a línea, la parte en campos $1, $2, … ($0 es la línea entera) y, para cada línea que cumple el patrón, ejecuta la acción. Variables útiles: NR (número de línea), NF (número de campos, así que $NF es el último). -F, indica que el separador es la coma (por defecto, espacios).

Columnas y filtros

terminal
$ awk -F, 'NR > 1 {print $1, $3}' medidas.csv | head -n 3    # nombre y tiempo, sin cabecera
ana 2.01
luis 1.98
marta 0.85
$ awk -F, 'NR > 1 && $4 > 22 {print $1, $2, $4}' medidas.csv  # temperatura > 22 °C
ana muelle 22.1
pedro caida 22.3
$ awk '{print $3}' render.log | sort | uniq -c                 # niveles del log (campos separados por espacios)
      1 ERROR
      6 INFO
      2 WARN

Compara con cut: awk entiende que varios espacios seguidos son un único separador, y además permite condiciones numéricas ($4 > 22) que ni cut ni grep pueden hacer.

Cálculos: BEGIN y END

El bloque BEGIN se ejecuta antes de leer nada y END al terminar. Las variables empiezan valiendo 0, sin declararlas:

terminal
$ awk -F, '$2 == "pendulo" {s += $3; n++} END {printf "media = %.3f s (n=%d)\n", s/n, n}' medidas.csv
media = 2.010 s (n=4)
$ grep -w fin render.log | awk -F'tiempo=' '{t += $2} END {printf "total: %.1f min\n", t/60}'
total: 92.0 min

Física · media y desviación típica del periodo

Para un péndulo de longitud L = 1 m, g = 4π²L / T². Con -v pasamos variables desde la shell, y printf funciona igual que en C:

$ awk -F, -v L=1.0 '$2 == "pendulo" {
      T = $3; g = 4 * 3.14159265^2 * L / (T*T)
      printf "%-6s T=%.2f s  g=%.2f m/s^2\n", $1, T, g }' medidas.csv
ana    T=2.01 s  g=9.77 m/s^2
luis   T=1.98 s  g=10.07 m/s^2
pedro  T=2.05 s  g=9.39 m/s^2
marta  T=2.00 s  g=9.87 m/s^2

Y la desviación típica muestral, s = √[(Σx² − n·x̄²)/(n−1)]:

$ awk -F, '$2 == "pendulo" {x = $3; s += x; s2 += x*x; n++}
      END {m = s/n; sd = sqrt((s2 - n*m*m)/(n-1)); printf "T = %.3f ± %.3f s\n", m, sd}' medidas.csv
T = 2.010 ± 0.029 s

Agrupar con arrays asociativos

Los arrays de awk se indexan con cadenas, lo que permite agrupar por una columna (como un «GROUP BY»):

terminal
$ awk -F, 'NR > 1 {s[$2] += $3; n[$2]++}
      END {for (e in s) printf "%-8s %.3f s\n", e, s[e]/n[e]}' medidas.csv | sort
caida    0.460 s
muelle   0.860 s
pendulo  2.010 s

Pista · scripts de awk

Cuando la orden crece, guárdala en un fichero media.awk y ejecútala con awk -F, -f media.awk medidas.csv. Recuerda las comillas simples alrededor del programa en la terminal: con dobles, la shell sustituiría $1 antes de que awk lo vea.

ElementoSignificado
$1, $2, …, $NFcampos; $0 la línea entera
NR / NFnúmero de línea / número de campos
-F,separador de campos (aquí, coma)
-v x=3define una variable antes de empezar
/regex/ {…}acción solo en líneas que coinciden con la expresión regular
$3 > 2 {…}acción solo si se cumple la condición
BEGIN {…} / END {…}antes de la primera línea / tras la última
printf, sqrt, exp, log, int, lengthfunciones como en C (y alguna más)

Ejercicios

  • Calcula la temperatura media, mínima y máxima de todas las medidas de medidas.csv.
  • Para cada escena del log, calcula el número de muestras por píxel multiplicado por el número de píxeles de ancho. (Usa -F'[ =]' para separar por espacios y por =.)
  • Haz que tu trazador escriba en stderr una línea fila N tiempo T por cada fila renderizada. Guarda stderr en un fichero y usa awk para encontrar la fila más lenta.
  • Genera con awk 'BEGIN {...}' (sin fichero de entrada) una tabla de sin x para x de 0 a 3,14 en pasos de 0,1, lista para dibujar con gnuplot.
