Parte 1 · Verdadero o Falso

10 preguntas · 1 pt c/u · 10 pts

Rodea V (verdadero) o F (falso). No hay que justificar.

  1. V · Frand() devuelve un número real entre 0 y 1.
  2. V · FSi nunca se llama a srand, rand() produce la misma secuencia de números en cada ejecución.
  3. V · FToda función recursiva necesita un caso base que detenga las llamadas.
  4. V · FEn un switch, si un case no termina con break (ni return), la ejecución continúa en el case siguiente.
  5. V · FLos valores de un enum son constantes enteras y, por defecto, el primero vale 0.
  6. V · FC permite que un struct herede de otro y tenga métodos virtuales, igual que una clase de C++.
  7. V · FTras la declaración adelantada struct material; se pueden declarar punteros de tipo struct material * aunque aún no se conozcan sus campos.
  8. V · FEs seguro guardar en una esfera la dirección de un material declarado como variable local de una función que ya ha terminado.
  9. V · FSi cam es de tipo camera *, el campo se lee con cam.vfov.
  10. V · Fpow, fmin y tan se declaran en <math.h> y requieren enlazar con -lm.

Parte 3 · Respuesta breve (5 pts c/u)

  1. Antialiasing: se lanzan samples_per_pixel rayos (p. ej. 100) por píxel, cada uno hacia un punto aleatorio dentro del píxel (desplazamiento en [−0.5, 0.5]), porque el píxel es un área y así se muestrean los bordes. Se suman los colores y se divide por el número de muestras (se multiplica por 1.0/N): el promedio suaviza los bordes en escalera.
  2. Recursión: una función que se llama a sí misma. Caso base: if (depth <= 0) return negro; (y también cuando el rayo no golpea nada y se devuelve el cielo). Llamada recursiva: ray_color(scattered, depth - 1, world). depth es el número de rebotes que le quedan al rayo.
  3. Polimorfismo sin clases: un único struct material con un campo type de tipo enum (LAMBERTIAN, METAL, DIELECTRIC) y los campos de todas las variantes (albedo, fuzz, refraction_index). Una sola función scatter hace switch (mat->type) y ejecuta el comportamiento de cada material.
  4. Salida por parámetro: recibe punteros color *attenuation y ray *scattered y escribe en ellos (*attenuation = ..., scattered->dir = ...); el que llama pasa &attenuation, &scattered. El int de retorno indica si el rayo se dispersa (1) o se absorbe (0).
  5. Puntero colgante: un puntero que apunta a una variable que ya no existe (salió de su bloque). Las esferas guardan punteros a los materiales (&mat_ground), y scatter los usa durante todo el render; si el material hubiera muerto, se leería basura. Por eso se declaran en main.
  6. Declaración adelantada: anunciar que un tipo existe sin dar sus detalles (struct material;). Permite declarar el puntero const struct material *mat dentro de hit_record sin incluir material.h, que a su vez necesita hit_record: rompe la dependencia circular entre cabeceras.

Parte 5 · Escribe (6 pts c/u)

  1. double random_double_range(double min, double max) {
    return min + (max - min) * random_double();
}
  2. Imprescindible: acumulador a cero, bucle, y factor 1.0 / samples_per_pixel (no 1 / ...). 
    color pixel = v3(0, 0, 0);
for (int s = 0; s < samples_per_pixel; s++)
    pixel = vec3_add(pixel, ray_color(get_ray(i, j), max_depth, world));
write_color(stdout, vec3_scale(pixel, 1.0 / samples_per_pixel));
  3. typedef enum { ESFERA, CUBO } forma;

double area(forma f, double r) {
    switch (f) {
    case ESFERA: return 4 * PI * r * r;
    case CUBO:   return 6 * r * r;
    }
    return 0;
}
