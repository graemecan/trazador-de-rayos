Intersección rayo-objeto

Añadir una esfera

Objetivo

Detectar cuándo un rayo golpea una esfera y pintar de rojo los píxeles que la ven. Es tu primer objeto de verdad en la escena.

Física · intersección rayo–esfera

Una esfera de centro C y radio r cumple (P − C)·(P − C) = r². Sustituimos P = P(t) = A + t·b y obtenemos una ecuación cuadrática en t: a t² − 2h t + c = 0, con a = b·b, h = b·(C−A), c = (C−A)·(C−A) − r². El discriminante h² − a·c nos dice cuántas soluciones reales hay: si es negativo, el rayo no toca la esfera; si es ≥ 0, sí.

Concepto de C · valores booleanos y condicionales

C (antes de C99) no tenía tipo booleano: se usa int, donde 0 es falso y cualquier otro valor es verdadero. Aquí una función devuelve un int que actúa como «¿golpea?». (Existe <stdbool.h> con bool, true y false; lo usaremos más adelante para mayor claridad.)

Pista · ¿por qué h en vez del clásico b?

Si defines la cuadrática como at² + bt + c, el término lineal b = −2·b·(C−A) lleva un factor 2 que luego se cancela. Escribiendo h = b·(C−A) (la «mitad de b») el discriminante queda h² − a·c y la fórmula final t = (h ± √(h²−ac))/a, más limpia. Es la misma optimización del libro original.
