Tarea5

Punteros y agregación

Normales de superficie y varios objetos

Objetivo

Calcular la normal en el punto de impacto (y visualizarla como color), y manejar una lista de esferas en lugar de una sola. Aquí aparecen los punteros y el paso de datos «por referencia», dos pilares de C.

Física · la normal de una esfera

La normal es el vector perpendicular a la superficie en el punto de impacto. Para una esfera es sencillísima: apunta del centro hacia el punto, n = (P − C)/r (ya normalizada al dividir por el radio). Visualizaremos n como color mapeando cada componente de [−1,1] a [0,1].

Concepto de C · punteros y «salida por parámetro»

Una función en C solo devuelve un valor. Pero al detectar un impacto queremos varios datos: el punto, la normal, la distancia t… La solución idiomática en C es pasar un puntero a una estructura hit_record y que la función la rellene: hit_record *rec. Dentro se accede con la flecha rec->t. La función devuelve solo un int («¿hubo impacto?»).

Concepto de C · arrays, & y la diferencia entre . y ->

El mundo es un array de sphere (un bloque de esferas contiguas) más un contador. Pasamos &temp (la dirección de temp) para que sphere_hit lo rellene. Con una variable normal se usa el punto (temp.t); con un puntero se usa la flecha (rec->t), que es azúcar para (*rec).t.

Concepto de C · sustituir la clase interval del original

El libro en C++ crea una clase interval para el rango [t_min, t_max]. Para no complicar el curso, en C pasamos ese rango como dos parámetros double. Es una traducción legítima: menos maquinaria, mismo resultado.
